HOST A SERVER

Version 0.5.6. Run your own multiplayer server. It gets its own address and certificate and shows up in the game's server list by itself.

Windows server 0.5.6 (55 MB) Linux server 0.5.6 (52 MB)
  1. Unpack the zip anywhere and keep everything in its folder together.
  2. Start atollrising-server (Windows: double-click atollrising-server.exe). Windows may say "Windows protected your PC" because the program is not signed yet: click More info, then Run anyway.
  3. Forward TCP port 25564 on your router to this computer, and allow it in the firewall. On Windows Server, run this in an administrator PowerShell:
    New-NetFirewallRule -DisplayName "Atoll Rising server" -Direction Inbound -Protocol TCP -LocalPort 25564 -Action Allow
  4. Keep the window open. It shows your server's address and says if the port can't be reached.

Automatic updates: from version 0.5.6 the server updates itself. Every 10 minutes it looks for a new version; when one is out and no game or room is open, it downloads it, checks that it is signed by Atoll Rising, installs it and starts again in the same window. Set "autoUpdate": false in atollrising-server.json to only be told instead.

Updating by hand (needed once to get to 0.5.6): stop the server, unpack the new zip into the same place as before so its folder lands on top of the old one, and let it replace the files. Your settings, identity and certificate are not in the zip and stay as they are. The server's first line shows its version.

Settings are in atollrising-server.json next to the program (title, name, port); see README.txt. Whoever runs a server runs its games, so the server can see everything in them.
